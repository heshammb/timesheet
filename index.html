Team Timesheet

Hours logged in the Azure DevOps Time Log tab, per person, project, work item and day, across all projects.

Create one in Azure DevOps → User settings → Personal access tokens, with Work Items: Read and Extension Data: Read. The token stays in your browser and is only sent to dev.azure.com.

No token? Use a saved file instead

Sign in to Azure DevOps, open the Time Log data, save the page (Ctrl/⌘+S), and choose the file below. Without a token, only work item numbers are shown (no project names).
